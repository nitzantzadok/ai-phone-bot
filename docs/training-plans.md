# תכניות אימון מגוגל שיטס

מודול שקורא את גיליון תכניות האימון, מנתח לכל מתאמן את משקלי העבודה
והדגשים לאורך כל החודשים, ובונה את התכנית לשבוע הבא.

## מה המערכת עושה

1. עוברת על כל לשונית בגיליון (לשונית = מתאמן)
2. מזהה את בלוקי החודשים, האימונים והתרגילים
3. אוספת את כל הדגשים - כלליים, ברמת החודש, ברמת האימון וברמת התרגיל
4. מחשבת לכל תרגיל את מגמת משקל העבודה לאורך החודשים
5. קובעת את המשקל לשבוע הבא לפי כללי פרוגרסיה + הדגשים
6. כותבת לשונית חדשה עם התכנית (או מדפיסה בלבד בהרצה יבשה)

**המשקלים מחושבים בקוד, לא על ידי מודל שפה.** GPT משמש רק לניסוח
פסקת הסיכום בעברית, והוא לא יכול לשנות משקלים, סטים או חזרות.

## הגדרה חד פעמית

### 1. יצירת Service Account

1. ב-Google Cloud Console: **IAM & Admin → Service Accounts → Create**
2. **Keys → Add Key → JSON** והורדת הקובץ
3. הפעלת ה-API: **APIs & Services → Library → Google Sheets API → Enable**

### 2. שיתוף הגיליון

לפתוח את הגיליון ולשתף אותו עם כתובת המייל של ה-Service Account
(נראית כמו `something@project.iam.gserviceaccount.com`) בהרשאת **עורך**.
בלי זה המערכת תקבל שגיאת הרשאה גם אם המפתח תקין.

### 3. משתני סביבה

```bash
TRAINING_SHEET_ID=1AbC...            # החלק הארוך מתוך כתובת הגיליון
GOOGLE_APPLICATION_CREDENTIALS=./config/google-credentials.json
# או לחלופין, המפתח כ-JSON בשורה אחת:
# GOOGLE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}

TRAINING_SHEET_SKIP_TABS=הוראות,מאגר תרגילים   # לשוניות שאינן מתאמנים
OPENAI_API_KEY=...                              # אופציונלי, לסיכום בעברית
```

## הרצה

```bash
npm run plans                              # הרצה יבשה - מדפיס למסך
npm run plans:write                        # כותב לשונית חדשה לכל מתאמן
node src/scripts/generateWeeklyPlans.js --trainee "דני כהן"
node src/scripts/generateWeeklyPlans.js --json plans.json
```

הרצה יבשה היא ברירת המחדל בכוונה - כדאי לעבור על הפלט לפני שכותבים
לגיליון. הכתיבה יוצרת לשונית חדשה בשם `תכנית שבועית DD.MM - שם המתאמן`
ולא נוגעת בלשוניות הקיימות.

## מבנה הגיליון

יש תבנית מוכנה לייבוא: `docs/templates/trainee-tab-template.csv`.
בגוגל שיטס: **קובץ → ייבוא → העלאה**, ולבחור **הוספת גיליון חדש**.

לשונית לכל מתאמן. בתוך הלשונית - בלוק לכל חודש:

| | | | | |
|---|---|---|---|---|
| **דגשים כלליים: מגבלת ברך שמאל** | | | | |
| **ינואר 2026** | | | | |
| **אימון 1 - פלג גוף תחתון** | | | | |
| תרגיל | סטים | חזרות | משקל עבודה | דגשים |
| סקוואט | 3 | 10 | 45 | |
| לג פרס | 3 | 12 | 80 | תקוע - לבדוק טווח תנועה |
| **אימון 2 - פלג גוף עליון** | | | | |
| תרגיל | סטים | חזרות | משקל עבודה | דגשים |
| לחיצת כתפיים | 3 | 10 | 15 | |

הזיהוי גמיש - אין צורך בעמודות במיקום קבוע:

- **חודש**: `ינואר 2026`, `חודש 3`, `01/2026`
- **אימון**: שורה שמתחילה ב-`אימון` או `יום`
- **כותרת טבלה**: שורה שמכילה `תרגיל` ולפחות אחת מ-`משקל` / `סטים` / `חזרות`
- **דגשים**: עמודת `דגשים`/`הערות`, או שורה חופשית שמתחילה ב-`דגשים:`
- **משקל**: `60`, `62.5 ק"ג`, `60, 62.5, 65` (נלקח האחרון), `משקל גוף`
- **סטים/חזרות**: עמודות נפרדות, או תא אחד `3x10`, או טווח `8-12`

## כללי הפרוגרסיה

| מצב | החלטה |
|---|---|
| מגמת עלייה | +5 ק"ג פלג גוף תחתון, +2.5 ק"ג פלג גוף עליון |
| משקל נמוך | הקפיצה מוקטנת כך שלא תעלה על ~10% מהמשקל |
| תקוע 2 מחזורים ומעלה | אותו משקל + חזרה אחת לסט |
| המשקל ירד | חזרה על אותו משקל |
| דגש שמעיד על זהירות | שמירה על אותו משקל |
| משקל גוף | חזרה נוספת לסט |

דגש שמזכיר אזור בגוף מוחל רק על התרגילים הרלוונטיים - הערה על הברך
תעצור סקוואט ולג פרס, אבל לא תעצור לחיצת כתפיים. דגש בלי אזור מסוים
("לא לעלות במשקל החודש") חל על כל התרגילים.

זיהוי אזור הגוף עובד ברמת מילה שלמה, כולל תחיליות וסופיות עבריות
("בכתף", "ברגליים"). זה מכוון: המילה "מגבלות" מכילה את הרצף "גב",
והתאמה פשוטה הייתה מסווגת כל דגש כזה כהערה על הגב.

מילות מפתח לזהירות: כאב, פציעה, דלקת, מגבלה, זהירות, תקוע, טכניקה,
שיקום, עייפות, עומס יתר, לא לעלות, לשמור משקל, להוריד משקל.
