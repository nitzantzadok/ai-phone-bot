# מערכת בניית תכניות אימון לסטודיו

מערכת **עצמאית לחלוטין** לבניית תכניות אימון שבועיות אישיות לכל מתאמני הסטודיו.
היא יושבת בתיקייה נפרדת, עם `package.json` משלה, ללא תלויות חיצוניות וללא כל קשר
לקוד, למסד הנתונים או לשירותים של מערכות אחרות במאגר. אפשר להעתיק את התיקייה
`studio-training/` כמו שהיא לכל מקום והיא תעבוד.

```bash
cd studio-training
npm run seed     # נתוני דמו: 7 סטודיואים שונים לגמרי, 13 מתאמנים
npm test         # 34 קבצי בדיקה, כולל מטריצת כיסוי של אלפי תכניות
npm run demo     # הדפסת תכניות לכל מתאמני הדמו
npm run build    # בניית מסך המאמן לקובץ HTML עצמאי אחד
npm start        # מסך המאמן: http://localhost:4310
```

מסך המאמן הוא קובץ יחיד שרץ במלואו בדפדפן — המנוע כולו נטען לצד ה-UI,
בלי שרת ובלי שליחת נתונים החוצה.

## מה המערכת לוקחת בחשבון

**המתאמן — מי הוא:** גיל (עם התאמות ייעודיות לנוער ולגיל השלישי), מין, גובה
ומשקל, רמת ניסיון, ותק אימונים, ואיכות התאוששות (שינה, סטרס, תזונה).

**המתאמן — מה הוא רוצה:** 13 מטרות — מסה, כוח, ירידה בשומן, כושר כללי, סיבולת,
כוח מתפרץ, שיקום, יציבה, ניידות, צפיפות עצם, תפקוד ועצמאות בגיל השלישי, ביצועים
בענף ספורט, והפגה ובריאות נפשית. לכל מטרה פרופיל מלא של סטים, חזרות, מנוחות, קצב,
RIR ועצימות.

**המתאמן — מה מגביל אותו:** 66 מגבלות רפואיות ופציעות — כתף, גב (כולל ההבחנה בין
פריצת דיסק לבין היצרות תעלה, שדורשות הפוך זו מזו), ברך, מרפק, שורש כף יד, ירך,
קרסול, צוואר, מפרקים מלאכותיים, רצפת אגן, הריון ואחרי לידה, לב וכלי דם, סוכרת,
אסתמה, אונקולוגיה, נוירולוגיה, היפרמוביליות, תשישות לאחר מאמץ ועוד. לכל מגבלה
שלוש דרגות חומרה שמשנות את קשיחות הסינון.

**המתאמן — מה קורה לו מחוץ לסטודיו:** ענף הספורט שהוא מתאמן בו וכמה פעמים בשבוע
(רץ שלוש פעמים בשבוע לא צריך עוד שלושה ימי רגליים), אורח החיים התעסוקתי, שבוע
נסיעה, אורכי אימון שונים בימים שונים, ושלב במחזור החודשי כקלט אופציונלי.

**הסטודיו:** מלאי הציוד המדויק *וכמות* כל פריט, מספר המתאמנים במקביל ומספר
המאמנים על הרצפה (מאמן שמשגיח על עשרה אנשים לא ילמד תרגיל טכני — והמערכת לא
תציע כזה), גובה תקרה, שטח פנוי, מגבלת רעש בבניין מגורים, המשקולת הכבדה ביותר
וקפיצת המשקל הקטנה ביותר, וסגנון הסטודיו — חדר כושר, פונקציונלי, בוטיק,
פילאטיס/ריפורמר, אגרוף, מרכז לגיל השלישי או סטודיו ביתי.

**התכנון עצמו:** חלוקה שבועית (גוף מלא / A-B / A-B-C / A-B-C-D / עליון-תחתון /
דחיפה-משיכה / PPL / לפי קבוצות שריר / מעגל תחנות / ניידות), פריסה על ימי השבוע
עם מרווחי התאוששות, סדר ביצוע נכון, סטי הכנה מתגברים לפני התרגיל הכבד, איזון
דפוסי תנועה, נפח שבועי לכל שריר, תדירות גירוי, תקציב עייפות יומי, תקציב זמן,
ופריודיזציה — צבירה, העצמה ושבוע הורדת עומס.

## איך זה עובד

```
מתאמן + סטודיו
      │
      ├─ normalize + validate ................ models.js
      │
      ├─ סינון: ציוד → פציעות → רמה → העדפות .. filters.js
      │        (כל פסילה מתועדת עם סיבה)
      │
      ├─ בחירת חלוקה ובניית שלד היום ......... split.js
      │
      ├─ מילוי משבצות בניקוד רב-משתני ........ select.js
      │        דפוס · חוב נפח · עודף נפח · מטרה · ציוד
      │        נדירות · גיוון · העדפות · עייפות
      │
      ├─ מרשם: סטים/חזרות/מנוחה/קצב/RIR ...... prescription.js
      │
      ├─ התאמה לתקציב זמן + השלמת נפח חסר .... generate.js
      │
      └─ בקרת איכות ......................... validate.js
               │
          תכנית שבועית + ציון איכות + ממצאים
```

**דחיסה לזמן אמת:** אם האימון לא נכנס בזמן שהוקצה, המערכת מוותרת בסדר שמאמן
מוותר בו — קודם סטים מהתרגיל הארוך, אחר כך קיצור מנוחות (עם הערה), ורק בסוף
ויתור על תרגיל שולי. אימון לעולם לא "גולש" מעבר לזמן שהמתאמן הקצה.

**עקרון מנחה:** אין "פלט קסום". כל תרגיל שנבחר נושא איתו את הניקוד שהביא לבחירתו
(`selection.detail`), את החלופות המדורגות, ואת ההערות המקצועיות — כך שהמאמן רואה
*למה* התכנית נראית כך, ויכול לחלוק עליה.

### בקרת האיכות
לפני שהתכנית מגיעה למאמן היא נבדקת: תרגיל כפול באותו אימון, תרגיל שסותר מגבלה,
ציוד חסר, טווח חזרות לא הגיוני, יחס דחיפה/משיכה, איזון סקוואט/הינג׳, שריר ללא
כיסוי, נפח מעל או מתחת ליעד, תדירות נמוכה, ואורך אימון חורג. `error` פוסל תכנית,
`warning` ו-`info` מוצגים למאמן להחלטה.

## לולאת המשוב מהשטח

המאמן מעביר את האימון דרך המסך, וליד כל תרגיל יש כפתורים. כל לחיצה היא אירוע
שמשנה את הפרופיל, ולכן את התכנית הבאה:

| כפתור | מה קורה |
|---|---|
| רישום סט (משקל/חזרות/RPE) | נשמר בהיסטוריה, ומחושב יעד לשבוע הבא בפרוגרסיה כפולה |
| קל מדי | +5% עומס. ארבעה דיווחים כאלה מעלים את רמת המתאמן |
| קשה מדי | −10% עומס, ונספר לטובת המלצת שבוע הורדת עומס |
| **כאב בתרגיל** | התרגיל מוסר; המפרק שדווח הופך למגבלה פעילה בחומרה לפי עוצמת הכאב — וכל התרגילים הסותרים אותה נעלמים מהתכנית הבאה |
| טכניקה מתפרקת | הורדת עומס; בתרגיל מורכב — החלפה בגרסה פשוטה יותר |
| מכשיר תפוס | הציוד נחסם, והתכנית הבאה נבנית בלעדיו |
| החלפת תרגיל | החלפה מיידית לחלופה מדורגת, עם חישוב מרשם מחדש ובקרת איכות חוזרת |
| דילוג | שני דילוגים על אותו תרגיל מסירים אותו |
| תרגיל מוצלח | מקבל עדיפות בהמשך |

הצטברות סימני עומס יתר (קשה מדי / דילוגים / כאב / RPE גבוה) מפעילה המלצה
לשבוע הורדת עומס ומקדמת אליו את המחזור.

## API

| נתיב | תיאור |
|---|---|
| `GET /api/meta` | טקסונומיה, מגבלות ורשימת תרגילים |
| `GET/POST /api/studios` | ניהול סטודיואים |
| `GET/POST /api/trainees` | ניהול מתאמנים |
| `POST /api/programs/generate` | תכנית למתאמן |
| `POST /api/programs/generate-all` | תכניות לכל מתאמני הסטודיו |
| `POST /api/programs/swap` | החלפת תרגיל בתכנית קיימת |
| `POST /api/feedback` | קליטת אירועי משוב מהשטח |
| `POST /api/next-week` | החלת המשוב, קידום שבוע ובניית התכנית הבאה |

שימוש כספרייה:

```js
import { buildProgram, buildStudioPrograms } from './studio-training/src/index.js';

const { ok, program, warnings } = buildProgram(trainee, studio);
const batch = buildStudioPrograms(allTrainees, studio);
```

## איך אני יודע שזה עובד לכל מקרה

`tests/matrix.test.js` לא בודק מקרה לדוגמה — הוא סורק את מרחב הקלט:

| מה נסרק | היקף |
|---|---|
| כל מגבלה × כל דרגת חומרה × שלושה סוגי סטודיו | ~500 תכניות |
| כל מטרה × כל רמה × 1-6 ימים × כל שבעת הסטודיואים | ~2,000 תכניות |
| פרופילים אקראיים (גיל, משקל, ספורט, אורח חיים, עד 4 מגבלות) | 600 תכניות |
| מקרי קיצון מוגדרים | סטודיו ללא ציוד, תקרה נמוכה, מגבלת רעש, שבוע נסיעה, שלוש מגבלות חריפות, הריון מתקדם, בן 16, בן 82, אימון של 20 דקות |

כל תכנית נבדקת בבדיקה עצמאית מהמנוע: אין תרגיל שסותר מגבלה, אין ציוד שלא קיים,
אין חריגה מהזמן, אין כפילות, אין עצימות מעל תקרת הגיל, ואין שגיאת בקרת איכות.

## הרחבה
- **תרגיל חדש:** רשומה אחת ב-`exercises.js`. הבדיקות מאמתות שכל השדות בטקסונומיה.
- **פציעה חדשה:** רשומה אחת ב-`constraints.js` — דגלים אסורים, תקרות עומס, תרגילים מומלצים והערה למאמן.
- **חלוקה חדשה:** ארכיטיפ ורצף ב-`split.js`.
- **מסד נתונים אמיתי:** להחליף את `store/db.js` מאחורי אותו ממשק.

## הסתייגות מקצועית
המערכת היא כלי עזר למאמן מוסמך ואינה מחליפה אבחון או ייעוץ רפואי. במצבים רפואיים
ופציעות נדרש אישור גורם מקצועי, והמאמן הוא הסמכות האחרונה בשטח.
